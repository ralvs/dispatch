04 · Missing surface

Link Ingest

You described a surface that accepts a URL via API, stores title / description / link, and lets you mark items read. That is not the current task-triage page.

Exists today

Task triage · /triage (from /inbox)

Open tasks in the system Inbox domain — assign a stewardship domain. Not a reading list.

  • Linked from Today triage strip
  • No URL / title / description model
  • Completing triage ≠ “mark as read”
Missing UI

Ingest · /ingest · mark as read

Share sheet / API posts a URL; system stores title, description, link; you process and mark read.

  • Primary nav slot (decided)
  • Unread count on Today alerts
  • Distinct from capture-to-task pipeline
